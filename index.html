About this page

This dashboard is the app's own output: the server refreshes PSProcLasso.ps1 -Snapshot every few seconds (same sampling code as the TUI — kernel thread-time CPU deltas, working-set RAM, and the Task Manager GPU counters) and serves the ranked table here. Numbers above 90% CPU are red, 50%+ amber. Click any column to re-rank, type to filter.
